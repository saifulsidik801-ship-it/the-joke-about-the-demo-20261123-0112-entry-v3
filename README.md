One line about working beside AI coding agents, written for the
[make.fun bounty](https://make.fun/bounty/the-joke-about-the-demo-20261123-0112).

`main.py` (Python 3.13, standard library only) writes the joke to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`). It is
deterministic: no network, no clock, no randomness.
